How to install on macOSInstall the series

  1. Download a screensaver, or all three, and unzip it.
  2. Double-click the .saver file and install it for your user account.
  3. Open System Settings, go to Screen Saver, then Other, and choose the scene.
  4. If the start time says Never, pick one in Lock Screen settings.

If macOS blocks the install

The downloads are signed but not yet notarized by Apple, so macOS may stop the first install. If you trust the file, open System Settings, then Privacy & Security, and choose Open Anyway. Keep Gatekeeper switched on. Checksums are in SHA256SUMS.txt.

New data every Monday

At 12:00 local time each screensaver checks capitolalpha.app for newly published data. If it isn’t running then, it checks on its next start. Offline, it uses the last data it saved or the set bundled in the download. Design changes need a new download.

Removing one

Delete its .saver file from ~/Library/Screen Savers/.

Compatibility

Universal builds for Apple Silicon and Intel Macs on macOS 12 Monterey or later. Tested on macOS Sequoia 15.6.1.

FAQNotes on the work

Are the screensavers free?

Yes. No account, no sign-up, no ads. Get all three in one small zip, or download each on its own.

Is the trading data real?

Yes. Every trade comes from public disclosures filed under the STOCK Act and collected by Capitol Trades. Laws come from Congress.gov, returns from daily closing prices against SPY. Filings report value ranges, so each amount is a representative value inside its range.

Which members of Congress appear?

99 members from both parties and both chambers, including Nancy Pelosi, Tommy Tuberville, Ro Khanna, Michael McCaul, Josh Gottheimer and John Fetterman. The set changes as new filings are published.

Do the screensavers show insider trading?

No. They show what members disclosed and when. Links between trades, laws and returns are visual heuristics, not evidence of causation, privileged information or unlawful conduct. The methodology explains how each scene is built.

Is there a Windows or iPhone version?

Not yet. The screensavers are macOS only. All five scenes also run in any browser at capitolalpha.app.
